# Unit 4 Prototype

This folder contains the prototype developed for the MSIT 5910 Capstone Project.

The **Technology Governance Assessment and Prioritization** prototype demonstrates how a small organization can assess selected technology governance practices against organizational factors, calculate scores, assign priority levels, and rank the practices based on their assessment results.

## Files

- **index.html:** Application structure and content
- **style.css:** Application styling
- **script.js:** Assessment scoring, priority classification, and ranking logic

This prototype is a demonstration tool. The broader governance assessment and prioritization process is **technology-neutral and can also be carried out manually without software**.
